# AI作業指示

このサービスは確定済みの道路グラフと指数コストから経路を選ぶ。指数を再計算せず、データ欠損・通行不能・低信頼度を明示的な制約またはコストに変換する。PostGIS/pgRouting導入後も、入出力契約と再現可能なテストを維持する。

`departure_advisor.py`はおすすめ出発時刻を予測するロジスティック回帰を実装する。これは経路探索本体（グラフコスト・順位・`drivability_score`）とは独立した、レスポンス直下の`departure_recommendation`だけに閉じた補助的な予測であり、`is_prediction`/`is_simulated`を明示する。経路選択やコスト計算へこの予測値を混入させない。

学習データ（`snowplow_segment_passages`の通過間隔）が実際に観測した経過時間の範囲を超えて予測させない（`LogisticModel.covers()`）。線形モデルは学習範囲外の入力に対して現実と無関係な方向へ飽和し得るため、範囲外の区間が一つでもあれば数値を出さず`insufficient_data: true`を返す。デモのGPSシミュレータは短時間しか稼働しないことが多く、この場合は「情報不足」が正しい応答である。
